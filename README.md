# 箱包外贸采购 · 供应链在途+产能 动态可视化看板

> 单 HTML 文件 · 内联全部 JS/CSS/数据 · 前端零后端、零 API · 双击即用 · 支持 GitHub Pages 自动部署

## 一、架构约束（已满足）

- **单 HTML 文件**：`index.html` 内联了 ECharts 库与 `data.json`（由 `build.py` 注入），双击即可在浏览器打开，无需任何服务器。
- **零后端 / 零 API**：所有计算在前端完成；敏感 token 只在 CI 构建侧（如需），绝不进入浏览器。
- **数据流水线**：`clean.py` 解析 Excel 源表 → 清洗 → 产出 `data.json`；`build.py` 把库与数据注入模板生成 `index.html`。

## 二、目录结构

```
supply-dashboard/
├─ index.template.html        # 前端源码（内联 CSS/JS，含占位符）
├─ clean.py                   # Excel → data.json 清洗脚本
├─ build.py                   # 注入 ECharts + data.json → index.html（单文件）
├─ run.py                     # 一键：clean + build
├─ refresh.bat / refresh.sh   # 双击刷新（Windows / Mac·Linux）
├─ src/                       # Excel 源表（替换此目录文件即可更新）
│  ├─ 采购订单.xlsx
│  ├─ 产能.xlsx
│  └─ 周计划.xlsx（可选，未提供时图 A/B 仅按在途剩余分组）
├─ vendor/echarts.min.js      # 本地 ECharts（构建时内联）
├─ data.json                  # 清洗产物
├─ index.html                 # 最终交付（单文件，双击即用）
└─ .github/workflows/deploy.yml  # GitHub Pages 自动部署
```

## 三、使用方式

### 本地更新数据（零代码）
1. 把新的「采购订单 / 产能 / 周计划」Excel 替换到 `src/` 目录（文件名含「采购订单」「产能」「周计划」即可自动识别）。
2. **双击 `refresh.bat`**（Mac/Linux 运行 `refresh.sh`）。
3. 自动重新生成 `index.html` 并打开浏览器，看板即同步刷新。

### 手动
```bash
python clean.py     # 解析 + 清洗 → data.json
python build.py     # 注入 → index.html
```

## 四、数据清洗规则（与需求一致）

| 步骤 | 规则 | 说明 |
|---|---|---|
| ① 删空单 | `单据编号` 为空/空白（含「合计」汇总行）跳过 | 计 `dropped_po`，不计入 |
| ② 删业务关闭 | `业务关闭` == `'业务关闭'` 的行跳过 | 计 `dropped_closed`；**保留「作废状态」列**在明细 |
| ③ SPU 取码 | `SPU = 物料编码` 仅留数字、取前 4 位 | `spu_of()` |
| ④ 交货日期 | 归一化 `YYYY-M-D` | `fmt_date()` |
| ⑤ 月份推导 | 由交货日期「月」→ `M月`；无日期记 `—` | 周计划按上传日期+31天 |
| ⑥ 标签取源 | 产线标签 / 时效标签 = 源表同名列（空则留空） | 不臆造 |
| ⑦ 字段映射 | 供应商简称 = 产能表.供应商简称（按供应商全称 join） | 同时得到采购负责人 / 月产能 |

### 计算口径
- **完成率** = 已收料数量 ÷ 采购数量（已收料 = 采购数量 − 剩余收料数量）
- **逾期** = 交货日期 < 今天 且 剩余收料 > 0
- **产能负荷率** = 订单计划总量 ÷ 月产能（有效产能）
- **状态**：周计划恒「待下单」；订单「正常 / 剩N天 / 逾期N天」
- **周产能** = 月有效产能 ÷ 该月 ISO 周数（非 ÷4）
- **核心供应商**：忆恩、佳俊、同光、拿可、宝莎、贝瑞卡、浩川、骏航、思哲

## 五、页面与功能

1. **在途概览**：4 张 KPI 卡 + 整体在途分布柱状图（核心/普通分组，点击下钻 SPU→SKU 抽屉）+ Top8 供应商占比环形图（在途剩余/已收料/采购总量切换）+ 逾期明细表。
2. **供应商分析**：标准/VMI 切换；按产线订单条形图（点击下钻）；产线/时效气泡图；产线收料与负荷汇总表（含 tfoot 合计）；逾期明细表。
3. **产能负荷分析**：负荷率分布条形图（点击联动详情表）；超额/饱和/空闲状态分布；核心/普通产能占比环形图；按月产能利用率趋势线。
4. **交叉分析**：全局切片器（供应商/月份/产线/时效/物料名称/SPU）+ 文本搜索，联动热力图、完成率趋势、产线占比。
5. **周数据计划**：分界值可调（默认 5000）；图 A（≥分界）/图 B（<分界）独立比例尺；点击柱下钻需下单明细。

所有图表支持点击钻取；明细表带 `tfoot` 总计；逾期 KPI 嵌入概览页与供应商页。

## 六、GitHub Pages 自动部署

1. 把本目录推送到 GitHub 仓库（含 `src/` 下的 xlsx 与 `.github/workflows/deploy.yml`）。
2. 仓库 Settings → Pages → Source 选 **GitHub Actions**。
3. 之后每次推送（或手动 Run workflow）即自动：清洗 Excel → 构建 `index.html` → 部署。
4. 替换源表后只需 `git add src && git commit && git push`，看板自动同步。
