▸ ③ 核查规则

点击展开口径说明与参数
已下单判定：「剩余数量」> 0 的行，整行视为尚未下单，数量按 0 计入；剩余数量 = 0 才按下单数量计入。
SKU 匹配（三级，由严到宽）：① 完整编码精确命中 → ② 剥掉上方前缀后再精确命中 → ③ 款级兜底：取编码内数字前四位为款号，同一款视为同一供应商生产。
状态过滤：下方排除词命中即整行不参与计算（逗号分隔，不分大小写）。
差异口径：按 SKU 汇总 — 差异数量 = 申请数量合计 − 有效下单数量合计；差异 > 0 即存在缺口，已下单量 = 0 记为「未下单」，其余记为「数量不足」。
注意：排除词是「包含匹配」。例如状态值为「未关闭」时，填「关闭」会把整表误排除；请填「已关闭」。
截止日期：—（按所选快捷方式自动算） 已作废 / 已关闭 状态自动排除
